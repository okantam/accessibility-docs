What happens to each format
FormatWhat the tool does
WordSets title and language, turns bold lines into real headings, marks table headers, darkens faint text, removes stacked blank lines, and collects alt text for every image (Claude drafts it).
PowerPointSets title and language, makes each slide's title read first, marks table headers, collects alt text for every picture and chart (Claude drafts it), and lists slides with missing or repeated titles.
R Markdown, QuartoAdds title and language, adds fig-alt to every plotting chunk (Claude drafts it from the code), fixes skipped heading levels, flags red/green palettes.
LaTeXTurns on PDF tagging, sets the PDF title, adds alt= text for every \includegraphics.
PDFChecks title, language, tags, and scanned pages, and shows the best way to fix it. Claude can rebuild it as an accessible web page or Quarto file with real math.

Before you post to Carmen

  • Open the fixed Word or PowerPoint file and run Review, then Check Accessibility. It catches things a file can't show this tool, like contrast against theme colors.
  • For Carmen pages, assignments, and discussions, run Carmen's built-in Accessibility Checker before publishing.
  • Videos need closed captions, and audio-only files need a transcript.
  • Don't post scanned pages of books or printouts; screen readers can't read them.
  • More guidance: Carmen Canvas Accessibility Guides from Ohio State's Digital Accessibility team.

This is an independent tool, not an official university service. Alt text and other judgment calls always need a person to review them.
